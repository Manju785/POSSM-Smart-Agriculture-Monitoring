POSSM – Smart Agriculture Monitoring System

Overview

The Pole Structured Pest and Fertilizer Monitoring System (POSSM)
is an ESP32-based smart agriculture monitoring system designed to
continuously monitor environmental and crop-related conditions.

The proposed system uses a centralized Master Pole architecture
integrating multiple sensors, camera-based monitoring, IoT
communication and real-time alert mechanisms.

 Key Features

- Temperature and humidity monitoring
- Soil moisture monitoring
- Gas concentration monitoring
- Light intensity monitoring
- Camera-based crop monitoring
- Threshold-based alerts
- LCD status display
- Buzzer-based local alerts
- IoT-based remote monitoring
- Solar-powered operation

 Hardware

- ESP32
- DHT22
- Soil Moisture Sensor
- MQ-2 Gas Sensor
- LDR
- ESP32-CAM
- LCD
- Buzzer
- Solar Power System

Working Principle

1. Sensors collect field parameters.
2. ESP32 receives and processes the sensor data.
3. Sensor values are compared with predefined thresholds.
4. Abnormal conditions trigger alerts.
5. Data is displayed locally and transmitted through the IoT platform.
6. The farmer can monitor field conditions remotely.


Project Outcomes

The system demonstrates real-time monitoring of environmental
parameters and provides alerts for potentially unfavorable
agricultural conditions.

Future Scope

- AI/ML-based pest classification
- Automated irrigation
- Automated fertilizer control
- Drone-assisted monitoring
- Multi-pole deployment
- Cloud-based analytics
